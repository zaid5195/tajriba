# سُفرة | قائمة رقمية
نموذج أولي لقائمة مطعم عربية متجاوبة مع الهاتف والكمبيوتر.

## الميزات
- واجهة عربية باتجاه RTL.
- البحث في أسماء الأطباق والأوصاف.
- تصفية حسب التصنيف.
- حفظ المفضلة محليًا في متصفح الزائر.
- طباعة القائمة.

## التشغيل
افتح `index.html` في المتصفح. لا يحتاج المشروع إلى خادم أو قاعدة بيانات.

## تخصيص القائمة
- غيّر اسم المطعم والنصوص في `index.html`.
- عدّل مصفوفة `dishes` في `app.js` لإضافة الأصناف وتغيير الأسعار والأوصاف.
- عدّل الألوان والخطوط في `style.css`.
- العملة الحالية يورو (€)، غيّرها في دالة عرض السعر داخل `app.js` إذا لزم.

## النشر باستخدام GitHub Pages
1. افتح Settings في المستودع.
2. اختر Pages.
3. اختر Deploy from a branch.
4. حدد الفرع main والمجلد /(root)، ثم Save.
5. انتظر حتى يظهر رابط الموقع في صفحة Pages.

## حدود النسخة الحالية
لا توجد لوحة إدارة، أو حسابات مستخدمين، أو طلبات عبر الإنترنت، أو دفع إلكتروني. المفضلة مخزنة في متصفح كل زائر فقط. الأسعار والأطباق بيانات تجريبية وليست قائمة حقيقية.

## نموذج العمل
يمكن تخصيص نسخة لكل مقهى أو مطعم مقابل أجر إعداد وتحديثات متفق عليها. ابدأ بعرض نموذج تجريبي على محل واحد وتحقق من اهتمامه قبل التوسع. الدخل غير مضمون. إذا كان صاحب المشروع دون 18 عامًا، يجب أن يشرف ولي الأمر على الاتفاقات التجارية والمدفوعات والالتزامات القانونية.
